# C++ Vacation Return Date Calculator

A C++ console application that calculates the expected vacation return date based on a starting date and the number of vacation days.

The program automatically handles weekends and adjusts the return date to the next business day.

## Features

- Calculate the day of the week for a given date
- Detect leap years
- Handle different month lengths
- Handle month and year transitions
- Detect weekends
- Identify business days
- Calculate vacation return dates
- Account for weekends during the vacation period
- Function overloading for date calculations
